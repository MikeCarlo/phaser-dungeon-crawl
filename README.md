# Phaser Dungeon Crawl

A touch-friendly Phaser 2D dungeon crawler prototype. Explore procedurally generated rooms and tunnels, move with a dynamic lower-half touch joystick, swing a sword, defeat enemies, and collect coins.

## Run locally

```bash
pnpm install
pnpm --filter @workspace/dungeon-crawler run dev
```

The game supports touch controls on phones and WASD/arrow keys plus Space on desktop.
